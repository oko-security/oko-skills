# Privacy (LINDDUN)

Runs when the team profile requires it or section 2 contains personal data.

| Category | Question |
|---|---|
| Linking | Can records be linked across contexts to build a profile? |
| Identifying | Can a pseudonymous subject be re-identified? |
| Non-repudiation | Are subjects unable to deny actions they should be able to deny? |
| Detecting | Can an observer learn that a subject is in the dataset? |
| Data disclosure | Is personal data exposed beyond its purpose? |
| Unawareness | Do subjects lack notice or control over processing? |
| Non-compliance | Does processing violate policy, consent, or regulation? |
